# تنبيهات خارج الموقع (واتساب / تيليجرام)

الإشعارات جوه الموقع بتفضل شغالة زي ما هي. الجديد: أي إشعار بيتولّد (طلب جديد، حالة جديدة، إيصال دفع، طبيب جديد، فشل توصيل...) بيتحط **في صندوق صادر داخل قاعدة البيانات** في نفس اللحظة، وبعدين الـ API بيبعته على واتساب و/أو تيليجرام. لو الإرسال فشل بيعيد المحاولة (بعد 1 ثم 4 ثم 9 ثم 16 دقيقة)، ولو فشل 5 مرات بيتعلّم "فشل" وبيظهر السبب في صفحة الإشعارات. يعني رسالة مش بتضيع حتى لو الـ API واقف ساعة.

الرسائل فيها **رقم الطلب أو الحالة واسم الدكتور ورابط الصفحة فقط**، من غير أي بيانات مريض.

## ⚠️ مهم: الـ API لازم يكون صاحي
اللي بيبعت الرسائل هو الـ API (كل 10 ثواني). لو استضافته مجانية وبتنام بعد فترة من غير استخدام (زي الخطة المجانية في Render)، الرسائل هتتأخر لحد ما يصحى. الحل:
- خطة مدفوعة بتشتغل طول الوقت، **أو**
- خدمة مراقبة مجانية (UptimeRobot مثلًا) تفتح `https://عنوان-الـAPI/health` كل 5 دقايق.

---

## الطريقة 1: تيليجرام (مجاني، وبتخلص في 5 دقايق) ← ابدأ بيها
1. في تيليجرام افتح **@BotFather** واكتب `/newbot`، اختار اسم و username (لازم ينتهي بـ `bot`). هيدّيك **Token**.
2. في إعدادات الـ API (Render ثم Environment) أضف:
   - `TELEGRAM_BOT_TOKEN` = التوكن
   - `TELEGRAM_BOT_USERNAME` = اسم البوت من غير `@`
   - `PUBLIC_WEB_URL` = عنوان موقعك (عشان اللينكات اللي في الرسائل)
   ثم أعد تشغيل الـ API.
3. ادخل الموقع على **الإشعارات** واضغط **ربط تيليجرام**. هيفتح تيليجرام، اضغط **Start**، وارجع للموقع هتلاقيه "متصل ✅".
4. اختار أنواع التنبيهات، واضغط **حفظ التنبيهات** ثم **إرسال رسالة تجريبية**.

كل موظف بيربط تيليجرام الخاص بيه، وبيوصله التنبيهات الخاصة بدوره بس (مثلًا المحاسب بيوصله الدفع، والمندوب بيوصله التوصيل).

## الطريقة 2: واتساب (الرسمي من Meta)
محتاج حساب **Meta for Developers** و**WhatsApp Business**، وفيه رسوم من Meta حسب الدولة ونوع الرسالة (راجع تسعيرهم). الرسالة اللي المعمل بيبدأها لازم تكون **قالب (Template) معتمد**.

1. ادخل developers.facebook.com، اعمل تطبيق من نوع **Business** وضيف منتج **WhatsApp**. هتاخد **Phone number ID** و**Access token**. للإنتاج اعمل **System User** وخد توكن دائم (التوكن المؤقت بينتهي بعد ساعات). رقم التجربة المجاني بيبعت لأرقام محدودة موثّقة بس.
2. في **WhatsApp Manager ثم Message templates** اعمل قالب:
   - الفئة: **Utility**، اللغة: **العربية** (`ar`).
   - النص لازم فيه **متغير واحد `{{1}}`**، وحط كلام ثابت **قبله وبعده** (Meta ممكن ترفض قالب بيبدأ أو بينتهي بمتغير)، مثال:
     `تنبيه من معمل سيتي سمايل: {{1}} . افتح الرابط للتفاصيل.`
   - انتظر الموافقة.
3. أضف في إعدادات الـ API:
   - `WHATSAPP_TOKEN` = التوكن (سري، في الـ API فقط)
   - `WHATSAPP_PHONE_NUMBER_ID`
   - `WHATSAPP_TEMPLATE` = اسم القالب بالظبط
   - `WHATSAPP_TEMPLATE_LANG` = `ar` (لازم يطابق لغة القالب)
   - `PUBLIC_WEB_URL` = عنوان الموقع
   ثم أعد تشغيل الـ API.
4. كل موظف يدخل **الإشعارات**، يكتب رقم واتساب بكود الدولة (مثال `201001234567`)، يفعّل واتساب، يحفظ، ويجرّب **إرسال رسالة تجريبية**.

واتساب متاح للموظفين بس (مش للأطباء)، عشان محدش يقدر يدخل رقم حد تاني ويبعتله رسائل.

## لو الرسالة ما وصلتش
افتح **الإشعارات** وشوف "آخر الرسائل الخارجية": لو "فشل" هتلاقي السبب تحته. أشهرها:
- `... is not configured on the server`: متغيرات البيئة ناقصة أو الـ API ما اتعملوش إعادة تشغيل.
- `401` من واتساب: التوكن غلط أو منتهي.
- `132001`/`template` من واتساب: اسم القالب أو اللغة مش مطابقين، أو القالب لسه مش معتمد.
- تيليجرام ما بيفتحش للرسالة: لازم الشخص يكون ضغط **Start** مع البوت.

> ملحوظة أمانة: تم اختبار منطق الإرسال وإعادة المحاولة وربط تيليجرام على خادم تجريبي محلي، لكن **الإرسال الفعلي لواتساب وتيليجرام لازم يتجرّب بحساباتك** قبل الاعتماد عليه.
